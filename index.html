适用于 Windows 10 / 11 LTSC 及移除 Xbox 组件的系统

连接手柄弹出 ms-gamebar 提示?一键修复

「需要新应用以打开此 ms-gamebar 链接」——一个脚本双击即修,之后完全无感:无弹窗、无任何窗口。

1下载脚本,双击运行

  1. 下载 fix.bat
  2. 双击运行,看到「修复完成」即可关闭
  3. 重新连接手柄——不会再有任何弹窗或窗口(无需重启)

⬇ 下载 fix.bat(一键修复) 还原 undo.bat

无需管理员权限:脚本只写入当前用户的注册表(HKCU)和一个空脚本文件,运行 undo.bat 可完整还原。

?原因与原理

  • 连接手柄(或按 Xbox 键)时,Windows 会通过 ms-gamebar:// 协议拉起 Xbox Game Bar。
  • LTSC 等精简系统没有该组件,注册表里也没有这个协议的处理器,系统找不到能打开它的应用,于是弹出「需要新应用」提示。
  • 修复思路:给 ms-gamebar 和 ms-gamebarservices 两个协议注册一个「空操作」处理器,让系统调用协议时静默成功、立即退出。
  • 处理器选用 GUI 子系统的 wscript.exe 执行空脚本——它从进程创建起就没有控制台窗口,所以连一闪而过的黑框都不会有,真正做到完全无感。

✦常见问题

需要管理员权限吗?

不需要。修复只写入当前用户的注册表(HKCU),每个 Windows 账户需各自运行一次 fix.bat。

有风险吗?如何还原?

新增的只是两个协议的空处理器,不影响系统其他功能。运行 undo.bat 即可完整还原(删除注册表项和空脚本)。

浏览器提示 .bat 有风险?

脚本是明文文本,可以用记事本打开查看全部内容再决定是否运行。它只做两件事:写一个空 .vbs 文件到 %LocalAppData%,以及用 reg add 写入协议注册。

为什么我的系统没有 Game Bar?

Windows 10/11 LTSC(长期服务版)面向精简场景,默认不包含 Microsoft Store、Xbox Game Bar 等组件。家庭版/专业版用户通常不会遇到此问题。

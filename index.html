适用于 Windows 10 / 11 LTSC 及移除 Xbox 组件的系统

连接手柄弹出 ms-gamebar 提示?一键修复

「需要新应用以打开此 ms-gamebar 链接」——双击导入注册表文件即可永久消除,无需管理员权限。

1下载并导入修复文件

  1. 下载 fix-ms-gamebar.reg
  2. 双击运行,在弹窗中选择「是」导入注册表
  3. 重新连接手柄,提示不会再出现(无需重启)

⬇ 下载修复文件 (.reg) 撤销 / 还原 (.reg)

仅写入当前用户的 HKCU\Software\Classes,不修改系统注册表;撤销文件可完整还原。

?原因是什么

  • 连接手柄(或按 Xbox 键)时,Windows 会通过 ms-gamebar:// 协议拉起 Xbox Game Bar。
  • LTSC 等精简系统没有该组件,注册表里也没有这个协议的处理器,系统找不到能打开它的应用,于是弹出「需要新应用」提示。
  • 修复思路:给 ms-gamebar 和 ms-gamebarservices 两个协议各注册一个「空操作」处理器——系统调用协议时静默执行并立即退出,弹窗自然消失。
查看修复文件内容 
Windows Registry Editor Version 5.00

[HKEY_CURRENT_USER\Software\Classes\ms-gamebar]
@="URL:ms-gamebar"
"URL Protocol"=""
"NoOpenWith"=""

[HKEY_CURRENT_USER\Software\Classes\ms-gamebar\shell\open\command]
@="\"C:\\Windows\\System32\\cmd.exe\" /c exit"

[HKEY_CURRENT_USER\Software\Classes\ms-gamebarservices]
@="URL:ms-gamebarservices"
"URL Protocol"=""
"NoOpenWith"=""

[HKEY_CURRENT_USER\Software\Classes\ms-gamebarservices\shell\open\command]
@="\"C:\\Windows\\System32\\cmd.exe\" /c exit"

✦进阶:彻底无黑框版本(可选)

基础版中处理器命令是 cmd.exe /c exit,极少数情况下连接手柄瞬间会闪过一个小黑框。如果介意,可改用无窗口版本:

  1. 下载 ms-gamebar-noop.vbs,放到 %LocalAppData% 目录(即 C:\Users\你的用户名\AppData\Local)
  2. 下载并导入 fix-noflash.reg(需先导入过基础版)

原理:改用 GUI 子系统的 wscript.exe 执行空脚本,从进程创建起就没有控制台窗口,原理上不可能闪框。

✦常见问题

需要管理员权限吗?

不需要。修复只写入当前用户的注册表(HKCU),每个 Windows 账户需各自导入一次。

导入后有风险吗?如何还原?

新增的只是两个协议的空处理器,不影响系统其他功能。下载 undo-ms-gamebar.reg 双击导入即可完整还原。

为什么我的系统没有 Game Bar?

Windows 10/11 LTSC(长期服务版)面向精简场景,默认不包含 Microsoft Store、Xbox Game Bar 等组件。家庭版/专业版用户通常不会遇到此问题。

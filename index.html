连接手柄总弹「需要新应用以打开 ms-gamebar 链接」?

LTSC 没装 Xbox Game Bar,系统找不到处理 ms-gamebar 协议的应用,每次连手柄都要弹一次。运行一次下面的脚本,以后就不再弹了。

下载 fix.bat undo.bat(还原用)

不需要管理员权限,双击运行即可。适用于 Windows 10/11 LTSC 及其他移除了 Xbox 组件的系统。

怎么用

  1. 下载 fix.bat
  2. 双击运行,看到「修复完成」后把窗口关掉
  3. 重新插一次手柄,弹窗不会再出现,不用重启
脚本只改动当前用户注册表和一个空脚本文件,想恢复原状就运行 undo.bat。

这个问题是怎么回事

现象

每次连接手柄(有线、蓝牙,或按手柄上的 Xbox 键)的瞬间,弹出「需要新应用以打开此 ms-gamebar 链接」。系统没有提供"不再提示"的选项,只能每次手动点掉。手柄本身不受影响,按键、震动都正常。

原因

完整版 Windows 里,Xbox Game Bar 在注册表注册了 ms-gamebar:// 和 ms-gamebarservices:// 两个协议。检测到手柄连接时,系统会调用协议去拉起 Game Bar 的提示界面。

LTSC 把 Xbox 组件整个砍掉了,这两个协议就注册表里根本没有对应的处理器。系统找不到任何应用来打开,只能退而弹出「需要新应用」的对话框——这就是弹窗的全部来由。

fix.bat 做了什么

  1. 在 %LocalAppData% 下放一个空脚本 ms-gamebar-noop.vbs,内容只有一行注释,运行即退出。
  2. 在当前用户注册表(HKCU\Software\Classes)给上面两个协议补上处理器,打开方式指向 wscript.exe //B //Nologo 加那个空脚本。

用 wscript.exe 而不是更直观的 cmd.exe /c exit,是因为 cmd 是控制台程序,个别机器上会闪一下黑框;而 wscript 属于 GUI 子系统,进程一创建就不带控制台窗口,//B //Nologo 再压掉错误提示和横幅,协议被调用时全程一个窗口都不会出现。

修好之后,系统调用协议会"正常打开"这个空处理器然后立即退出,弹窗的触发条件就不存在了。

为什么能放心还原

这个问题的成因是缺东西而不是多了什么,所以修法是补一个安静的占位处理器,不删不改系统里任何现有配置。undo.bat 把新增的注册表项和脚本文件删掉,系统就回到原始状态。

其他问题

需要管理员权限吗?
不需要。改动只在 HKCU,如果你换了 Windows 账户,新账户要再跑一次 fix.bat。

浏览器拦截 .bat 下载?
脚本是明文文本,用记事本打开就能看到全部内容:写一个 vbs 文件,执行几条 reg add,仅此而已。确认没问题再运行。

为什么我的系统没有 Game Bar?
LTSC 面向精简场景,默认不带 Microsoft Store 和 Xbox 组件。家庭版、专业版用户一般不会碰到这个问题。
